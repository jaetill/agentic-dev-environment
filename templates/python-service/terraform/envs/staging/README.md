# staging environment

Same shape as dev (see `../dev/README.md`). Differences:

- State key: `{{project_name}}/staging/terraform.tfstate`
- `LOG_LEVEL=INFO`
- Larger Lambda memory / longer timeout if needed
- 30-day log retention per ADR-0009 §1

The full `main.tf`, `backend.tf`, `providers.tf`, `variables.tf`, `terraform.tfvars.example` files mirror dev with env-specific values. Generated by the bootstrap script.
