# prod environment

Same shape as dev/staging. Differences:

- State key: `{{project_name}}/prod/terraform.tfstate`
- `LOG_LEVEL=INFO`
- Production-sized Lambda memory + timeout
- 90-day log retention per ADR-0009 §1
- AWS Budgets configured for prod ($200/mo default per ADR-0007 §6)
- IAM trust policy restricted to `main` branch + tag-pushed deploys only

The full `main.tf`, `backend.tf`, `providers.tf`, `variables.tf`, `terraform.tfvars.example` files mirror dev with env-specific values. Generated by the bootstrap script.

**No human-in-the-loop for prod deploys** per ADR-0003 — they happen automatically through release-please tag → staging-verification → auto-promote.
